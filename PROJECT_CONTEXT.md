## Review evidence and prioritized future work

The detailed [review](runs/2026-11-05/improvement/REVIEW.md) separates verified facts from proposals. Recommended order:

1. **Sampler coverage**: quantile strata already have 435/436 examples each, but replacement draws cover only 1,355 distinct examples in the reproduced first epoch (2,180 draws, 273 batches). Compare seeded shuffled/no-replacement coverage while preserving the selected model, data, schedule and evaluation. Do not falsely claim current quantile strata balance fixed shallow/deep metre intervals.
2. **Mask-aware physics reference**: `forward` calculates the green-band 95th percentile over the entire patch, including masked pixels. Write an invariance test that changes only invalid pixels; mask the reference calculation with an explicit empty-mask policy. Verify that invalid values cannot alter valid-pixel priors. Accuracy improvement is a hypothesis, not demonstrated.
3. **Loss objective ablation**: `w_mse` actually weights normalized Huber, while NLL uses metre residuals. This is not a proven units bug after the earlier fix, but relative objective weighting may matter for RMSE. Log term magnitudes/gradients; compare explicit normalized MSE or adjusted NLL weight one at a time. Preserve finite/variance checks.
4. **Error/data audit**: five largest validation errors account for 38.4% of squared error; map them against cloud/glint/coast/reference-cell quality. Do not remove hard validation/test samples to improve scores. Audit clear-observation counts, bathymetry resolution and valid-water masking.

A modest continuation is plausible, not guaranteed. Preserve/reconfigure scheduler state explicitly: simply increasing epochs with period 180 causes another restart, not low-LR continuation. The current resume loader restores scheduler state and can override edited schedule settings.
